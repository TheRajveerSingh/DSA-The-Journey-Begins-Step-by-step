# DSA: The Journey Begins 🚀

A comprehensive Data Structures and Algorithms learning repository with C++ implementations, organized from fundamentals to advanced topics.

## 📁 Repository Structure

- `p002_loops.cpp` - For loops and basic iteration
- `p003_factorial.cpp` - Factorial calculation
- `p004_prime.cpp` - Prime number checking
- `p005_fibb.cpp` - Fibonacci sequence generation
- `p006_patterns.cpp` - Pattern printing exercises
- `p007_whileloops.cpp` - While loop implementations
- `p008_sumofnum.cpp` - Sum of numbers
- `p009_dowhile.cpp` - Do-while loop practice
- `p010_brcon.cpp` - Break and continue statements
- `p011_switch.cpp` - Switch case statements
- `p012_dectobin.cpp` - Decimal to binary conversion
- `p013_leapyear.cpp` - Leap year checker
- `p014_revint.cpp` - Integer reversal
- `p015_pow2.cpp` - Power of 2
- `p016_palindrome.cpp` - Palindrome checker
- `p017_compnum.cpp` - Complex number operations

### 2. **DSA Stage 1** - Core Data Structures & Algorithms
Organized by topic with progressive difficulty:

## 🎯 How to Use This Repository

1. **Start with Fundamentals**: Begin with `c++ norm progs/` to strengthen basic C++ concepts
2. **Learn Topics**: Progress through `dsa stage 1/` topics in order
3. **Practice Problems**: Solve problems in `Problems/` for each topic
4. **Reference Templates**: Use templates in `Templates/` when coding solutions
5. **Iterate**: Revisit and refactor solutions for better understanding

## 🛠️ Prerequisites

- **C++ Compiler**: GCC, Clang, or MSVC
- **Editor**: VS Code or any C++ IDE
- **Knowledge**: Basic programming experience

## 📝 Compilation & Execution

### Compile a single file:
```bash
g++ -o output filename.cpp
```

### Run:
```bash
./output
```

### With fast I/O:
```bash
g++ -O2 -o output filename.cpp
./output
```
